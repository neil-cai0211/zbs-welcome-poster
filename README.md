# ZBS POS 新人欢迎海报

一个为 ZBS POS **销售线新人**制作双语欢迎海报的 Codex 技能。从薪人薪事最新提交的入职表单取材，按固定字号在本机排版。每人交付一份可编辑的 `欢迎海报.psd` 和一张可直接使用的 `欢迎海报.png`，尺寸均为 1700 × 1700 px。

## 在 Codex 里使用

安装后，在 Codex 中输入下面这句话即可开始。

> 用 `$zbs-welcome-poster` 给最近一位销售新人做欢迎海报。

也可以指定新人姓名。Codex 会在「全部」审批中查找该人最新提交的「待入职员工信息审核」表单，审核中也可使用。遇到同名无法区分、资料缺失或照片不合格时，会说明原因并暂停。首次遇到其他部门时，需要先确认对应的部门、岗位和样稿。

## 首次安装

1. 准备 Windows、Git、Python 3.12、uv、Bahnschrift 和微软雅黑粗体。读取入职表单还需要已获授权的薪人薪事账号和本机可用的 ego-browser。
2. 在 PowerShell 中运行以下命令，将技能安装到 Codex 默认技能目录。

   ```powershell
   $skillDir = Join-Path $env:USERPROFILE '.codex\skills\zbs-welcome-poster'
   git clone https://github.com/neil-cai0211/zbs-welcome-poster.git $skillDir
   Set-Location -LiteralPath $skillDir
   ```

3. 在本机准备两份经授权的原始模板。空白底稿是 `【交付】新人欢迎-空白.psd`，销售样稿是 `【交付】新人欢迎-销售.psd`。默认从当前用户桌面读取，放在其他位置时可用 `--blank` 和 `--sales` 指定路径。
4. 在技能目录中安装依赖并下载人像模型，然后在新的 Codex 对话中使用上面的示例指令。安装命令见[本地运行说明](references/run.md)。

## 海报如何排版

| 区域 | 规则 |
| --- | --- |
| 姓名与岗位 | 姓名使用英文名和姓氏拼写，英文全大写。销售红框使用 SALES DPT. 和 TELESALES，中文岗位为“初级销售代表”。 |
| 最爱的电影、爱好 | 保留中文并补充英文。英文以 43 pt、中文以 35 pt 起排。短词保持字号，长内容先换行，仍放不下时再缩小。 |
| 座右铭 | 保留原文并翻译，按语义换行，再按栏宽调整字号。一段 30 个汉字的实测文案中，中文排成三行、英文排成四行；实际行数随文案变化。 |
| 人物 | 使用五官清楚的单人正面生活照。抠去背景，检查发丝、指尖和指缝，将人物置于顶层，底边贴部门红框上缘。 |

## 输入与交付

正式制图使用表单中的姓名、英文名、生活照、最爱的电影、爱好和座右铭。只有用户明确要求测试代填时才使用测试文案。原始表单、员工照片、中间文件和成品保存在获准的本地受限目录。导出时会读回 PSD 核对新增的 17 个可编辑文字层，并比对其合成预览与 PNG。

完整的选人、取数、照片核验和异常处理规则见[技能说明](SKILL.md)。
